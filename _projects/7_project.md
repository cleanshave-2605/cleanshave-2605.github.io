Course project, CS 626 | Prof. Pushpak Bhattacharya | October–December 2024.

- Classified 20,000 Hindi sentences into five distinct emotion classes using deep learning models.
- Verified 162 scenarios covering nine deep learning models, six dataset variations, and three word-embedding techniques.
- Attained 84.3% accuracy using TextBlob embeddings and mBERT with human-annotated labels.
